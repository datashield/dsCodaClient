# Package index

## Server-side assignment

Create objects on the servers; nothing is returned to the client.

- [`ds.lrEM()`](https://github.com/datashield/dsCodaClient/reference/ds.lrEM.md)
  : Creates a server-side log-ratio EM algorithm object for
  compositional data imputation
- [`ds.acomp()`](https://github.com/datashield/dsCodaClient/reference/ds.acomp.md)
  : Creates a server-side Aitchison composition object for compositional
  data analysis
- [`ds.ilr()`](https://github.com/datashield/dsCodaClient/reference/ds.ilr.md)
  : Creates server-side ILR coordinates for compositional data analysis

## Client-side helpers

- [`ds.meanComp()`](https://github.com/datashield/dsCodaClient/reference/ds.meanComp.md)
  : Compute mean composition via ILR mean and inverse transform
- [`build_sequential_ilr_V()`](https://github.com/datashield/dsCodaClient/reference/build_sequential_ilr_V.md)
  : Build sequential ILR basis matrix (sequential binary partition)
